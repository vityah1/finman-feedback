# FinMan Feedback & Roadmap

**FinMan** is a smart personal finance app for individuals, families, and landlords.

🔗 **Try it free:** [finmanapp.com](https://finmanapp.com?utm_source=github)

---

## What is this repo?

This is a public space for:
- **Bug reports** — found something broken? Open an issue!
- **Feature requests** — have an idea? We'd love to hear it.
- **Roadmap** — see what's planned and in progress.
- **Changelog** — track what's new in each release.

No source code here — just transparent communication with users.

## How to submit feedback

1. Go to the [Issues tab](../../issues)
2. Click **New issue**
3. Choose a template (Bug report / Feature request) or write freely
4. Submit — we'll respond!

## Key Features of FinMan

- 🏦 **AI bank import** — upload statements from any bank, AI auto-categorizes transactions
- 📸 **Utility meter readings via Telegram** — send a photo, AI reads the numbers
- 🚗 **Car expenses & mileage tracking** — fuel cost per km/mile, auto-calculated
- 👨‍👩‍👧 **Family budget** — shared access for household members
- 🌍 **Multi-currency & multi-language** (UA/EN)
